Same network, three different decisions

One French logistics network (3 existing warehouses, 20 real French cities, distances computed from real coordinates). Three dashboards, each built for a different person and a different decision. Demand is estimated from population (an illustrative proxy, not real shipment data), and the cost figures are illustrative assumptions. See the README for the full reasoning.

Sustainability / CSR manager

CO2 dashboard

Which routes should we prioritize to cut network CO2? A ranked bar chart plus a map-like scatter, because the decision is about both "how much" and "where".
Logistics / operations manager

Cost dashboard

Where does cost concentrate, transport or storage, for each warehouse? A stacked bar chart plus a table of exact figures, because the decision is which lever to pull.
Strategic / network planning manager

Network dashboard

Should we open a warehouse in Bordeaux or Marseille, or close Lille? A bar chart of scenarios plus side-by-side maps, because this decision is geographic.
